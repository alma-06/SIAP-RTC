# EXP-03 — Excel ejecutivo institucional

## Objetivo
Evolucionar la salida XLSX desde una ficha mínima hacia un libro ejecutivo autocontenido y trazable.

## Hojas
1. `Resumen ejecutivo` — lectura inmediata del periodo.
2. `Indicadores` — valores ejecutivos.
3. `Alertas` — condiciones que requieren revisión.
4. `Evidencia` — identificación del corte y evidencia asociada.
5. `Comparativo` — estructura inicial para comparación histórica.

## Principio de trazabilidad
El libro conserva el `Evidence ID` y el estado de comparabilidad junto con los resultados.

## Alcance actual
Esta entrega establece la estructura funcional. La incorporación de detalle granular, fórmulas visibles, filtros, gráficos institucionales y metadatos completos de fuente se realizará cuando esos datos estén disponibles en el contrato de exportación.
