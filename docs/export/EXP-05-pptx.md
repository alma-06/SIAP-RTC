# EXP-05 — Exportador PowerPoint ejecutivo

## Objetivo
Generar una diapositiva ejecutiva a partir del mismo `ExportPayload` utilizado por Excel y Word.

## Contenido inicial
- título y periodo;
- cuatro indicadores principales;
- estado de comparabilidad;
- alertas;
- identificador de evidencia.

## Regla de consistencia
El exportador no recalcula indicadores ni consulta directamente las fuentes RTC.

## Alcance
Esta versión establece el motor funcional y la composición inicial. La identidad gráfica institucional, gráficas históricas, diapositivas adicionales y plantilla definitiva se incorporarán en la fase de presentación.
