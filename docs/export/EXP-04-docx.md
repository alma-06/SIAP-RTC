# EXP-04 — Exportador Word ejecutivo

## Objetivo
Generar un documento institucional a partir del mismo `ExportPayload` utilizado por Excel.

## Estructura
- título y subtítulo;
- identificación del periodo y estado;
- indicadores ejecutivos;
- alertas y consideraciones;
- trazabilidad mediante Evidence ID.

## Regla de consistencia
El exportador Word no consulta fuentes RTC ni recalcula indicadores. Consume exclusivamente `ExportPayload`.

## Alcance inicial
La versión funcional establece la estructura y contenido. La identidad gráfica institucional, encabezados, pies, numeración y plantillas definitivas se incorporarán en una fase de presentación.
