# SIAP-RTC 0.1.0-rc1 — Notas de versión

## Propósito
Primera versión candidata destinada exclusivamente a pruebas funcionales controladas.

## Incluye
- arquitectura de aplicación y dominio;
- importación RTC;
- filtrado de `CAM. SEN.`;
- deduplicación;
- persistencia histórica SQLite;
- auditoría de lotes;
- reportes ejecutivos;
- configuración de rutas de producción;
- preparación de empaquetado Windows;
- suite de pruebas automatizadas.

## No incluye aprobación para producción
Esta versión no debe utilizarse todavía como sistema institucional de producción. Su objetivo es obtener evidencia de aceptación funcional y detectar ajustes antes de una versión estable.

## Validación prevista
La validación debe utilizar archivos RTC de prueba o copias autorizadas y comprobar el resultado contra una conciliación manual independiente.

## Criterio de avance
Los defectos críticos o altos deben corregirse antes de una versión estable. Las observaciones menores deberán registrarse para el siguiente ciclo.
