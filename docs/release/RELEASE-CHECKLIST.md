# SIAP-RTC — Release Candidate Checklist

## Código

- [ ] Suite normal de pruebas en verde.
- [ ] Sin cambios locales no versionados.
- [ ] Versión identificada.
- [ ] Dependencias fijadas.

## Datos

- [ ] Ruta de SQLite configurable.
- [ ] Directorios de datos separados de los binarios.
- [ ] No se incluyen bases institucionales en el instalador.

## Instalación

- [ ] Instalación limpia.
- [ ] Ejecución como usuario estándar.
- [ ] Creación inicial de directorios.
- [ ] Persistencia de la base después de reiniciar.
- [ ] Desinstalación sin pérdida accidental de datos.

## Operación

- [ ] Importación de uno y varios Excel.
- [ ] Filtrado CAM. SEN.
- [ ] Deduplicación.
- [ ] Histórico.
- [ ] Auditoría.
- [ ] Reporte ejecutivo.

## Evidencia

- [ ] Artefacto instalable generado.
- [ ] SHA-256 del artefacto.
- [ ] Notas de versión.
- [ ] Procedimiento de instalación.
- [ ] Procedimiento de actualización.
- [ ] Procedimiento de respaldo/restauración.
