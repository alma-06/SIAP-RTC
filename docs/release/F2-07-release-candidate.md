# F2-07 — Versión candidata SIAP-RTC

## Identificador propuesto
`SIAP-RTC v0.1.0-rc1`

## Alcance
Primera versión candidata del motor integrado, incluyendo ingesta, validación previa, reglas de negocio, conciliación, Criterio 78 auditable, histórico, exportación documental y verificación de paquetes.

## Criterios de liberación
1. Pruebas unitarias y de integración críticas aprobadas.
2. Matriz F2-06 sin fallas críticas abiertas.
3. Reglas de negocio documentadas y consistentes con el comportamiento implementado.
4. Criterio 78 reproducible y con parámetros auditables.
5. Histórico sin sobrescritura silenciosa.
6. Manifiestos y SHA-256 verificables.
7. Limitaciones conocidas documentadas.

## Estado
Este documento define el criterio de liberación; no declara por sí mismo que la versión ya haya sido aprobada para producción.

## Pendiente antes de producción
Prueba con archivos RTC reales representativos, revisión de resultados por el área responsable y validación final de los entregables institucionales.

## Regla de gobernanza
La etiqueta `rc1` representa una versión candidata para validación, no una autorización de uso institucional en producción.
