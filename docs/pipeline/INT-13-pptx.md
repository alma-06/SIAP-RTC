# INT-13 — Presentación ejecutiva PPTX

## Objetivo
Generar una presentación ejecutiva a partir del mismo `IntegratedPipelineResult` utilizado por XLSX y DOCX.

## Estructura mínima
1. Portada y periodo.
2. Resultados del procesamiento.
3. Indicadores de conciliación, cuando existe comparación.
4. Consideraciones metodológicas.

## Principio
La presentación no recalcula datos. Consume el resumen ejecutivo derivado del pipeline integrado.

## Diseño
La primera versión prioriza legibilidad y síntesis. Las visualizaciones avanzadas se incorporarán cuando exista un conjunto de datos representativo y validado.
